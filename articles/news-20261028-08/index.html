AI・システム

1. Google、リアルタイムで操作できるワールドモデル「Genie 4」を発表

Googleは2026年10月27日（米国時間）、リアルタイムのインタラクティブなシミュレーション向けの新しいワールドモデル「Genie 4」を発表しました [1]。 自然言語でカメラの移動、天候の変更、キャラクターの追加などをリアルタイムに指示でき、環境音や音楽、対話などの音声もその場で生成するとしています [1]。 現時点では限られたテスターに提供を始めた段階で、Google AI Ultraの契約者向けの「Project Genie」と、Gemini APIおよびAI Studioの早期アクセスパートナー向けには近日提供予定としています。料金や提供地域は記載されていません [1]。

企業・担当者が確認すること： Gemini APIでの利用を検討する場合は、早期アクセスの案内や料金の公表を待ってから評価してください（当サイトの見解）。

2. Claude Sonnet 5.5で10月27日にエラー増加が2回発生、いずれも解決

AnthropicのステータスページによるとClaude Sonnet 5.5へのリクエストで、2026年10月27日にエラーの増加が2回発生しました [2][3]。 1回目は09:14 UTC（日本時間18:14）に調査を開始し、09:38 UTCに修正を適用、09:56 UTC（同18:56）に解決しています [2]。 2回目はclaude.ai、Claude API、Claude Code、Claude Coworkに影響し、影響期間は14:42 UTCから15:17 UTC（日本時間23:42から28日0:17）としています [3]。

企業・担当者が確認すること： 該当時間帯にClaude Sonnet 5.5を使う処理でエラーが出ていた場合は、失敗したリクエストの再実行要否を確認してください（当サイトの見解）。

3. GitHub Copilot、組織にインストールしたGitHub Appによるサーバー間認証に対応（パブリックプレビュー）

GitHubは2026年10月27日（米国時間）、組織にインストールしたGitHub Appによるサーバー間認証にGitHub Copilotが対応したと公表しました。パブリックプレビューとしての提供です [4]。 GitHub Copilot SDKで作ったサービスやエージェントが、サインインしたユーザーの認証情報に頼らず、組織として要求を送れるようになります。GitHub Appに読み取り専用の「Copilot Requests」組織権限を与え、短時間有効なインストールアクセストークンをSDKに渡す仕組みです [4]。 利用量はインストール先の組織に計上・請求され、組織のモデルポリシーや予算、利用額の管理が適用されます。組織のオーナーは、AI利用状況のCSVレポートの app_client_id でアプリごとの利用を確認でき、アプリの停止またはアンインストールでアクセスを止められます [4]。

企業・担当者が確認すること： 組織のオーナーは、Copilot Requests権限を持つGitHub Appの一覧と、アプリ経由の利用量を定期的に確認してください [4]。

セキュリティ

4. 【続報】お名前.com デスクトップクラウドへの不正アクセス、GMOが特別お見舞金と懸賞金制度を公表

GMOインターネットグループは2026年10月27日、「お名前.com デスクトップクラウド」への不正アクセスについて第12報（19:10時点）を公表しました。攻撃者とみられる者からの要求には応じない方針をあらためて示しています [5]。 情報が公開された顧客には、公開された情報の区分に応じて1万円から2.5万円の特別お見舞金を支払うとしており、上限は1公開につき300万円です。第4報で示した一律5,000円のお見舞金や、不正取引による損失の補償とは別に支払うとしています [5]。 また、犯人の特定につながる情報を募る「GMOサイバー犯罪撲滅・懸賞金」を設け、報奨金の総額上限を100万米ドルとしました。受付は10月28日12:00（日本時間）に始まり、期間は犯人逮捕までです [5]。

企業・担当者が確認すること： 公開されたとされる情報にはアクセスせず、拡散もしないでください。同社はパスワードや認証コードを尋ねることはなく、「被害金を取り戻す」などの名目で費用を求める連絡にも応じないよう呼びかけています [5]。
