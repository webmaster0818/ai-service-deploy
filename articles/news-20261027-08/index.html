AI・システム・セキュリティのニュースまとめ（2026年10月27日 8時）

公開 2026-10-27　AIサービス比較ナビ 編集部

2026年10月26日18時から27日8時までに確認したニュースのうち、公式発表を確認できた4件をまとめました（AI分野1件・セキュリティ分野3件・うち続報1件）。 OpenAIが新モデル「GPT-6.1 Terra」をAPIで公開したほか、CloudflareはWorkers AIの一部モデルで他の利用者の依頼内容が応答に混入していたことを公表しました。

当サイトでは、各社・各機関の公式発表を開いて内容を照合したうえで掲載しています。数字や日付は各項目末尾の出典番号から確認できます。

AI

1. OpenAI、新モデル「GPT-6.1 Terra」をAPIで公開、GitHub Copilotでも提供開始

OpenAIは2026年10月26日、APIの変更履歴で新モデル「GPT-6.1 Terra」の公開を告知しました。画像を使った推論、精度の高いコンピューター操作、自然な文章作成に向けた、高速で効率的なモデルと説明しています。Responses APIとChat Completions APIで利用できます [1]。 モデルの説明ページによると、コンテキストウィンドウは1,050,000トークン、最大出力は128,000トークン、知識の基準日は2026年6月1日です。料金は100万トークンあたり入力1ドル、出力5ドルで、入力が272,000トークンを超える依頼は入力2倍・出力1.5倍の料金になります [2]。 GitHubも同日、GitHub CopilotのPro、Pro+、Max、Business、Enterpriseの各プランでGPT-6.1 Terraの提供を始めました。提供は段階的に進めるとしています [3]。

企業・担当者が確認すること： GitHub CopilotのBusiness・Enterpriseでは、管理者が全体の既定設定をオフにしていない限り、新しいモデルは既定で有効になります。社内で利用モデルを管理している場合は、Copilot設定のモデルポリシーを確認してください [3]。APIで切り替えを検討する場合は、長い入力で料金が変わる点も含めて試算してください [2]。

セキュリティ

2. Cloudflare、Workers AIの「GLM-5.3」で他の利用者の依頼内容が応答に混入していたと公表

Cloudflareは2026年10月26日、Workers AIで提供していたモデル「GLM-5.3」で、ごく一部の利用者が、同じモデルへの他の利用者の依頼内容を含む応答を受け取っていたと公表しました。影響を受けた応答は計155件で、いずれも681,280トークンを超える長い入力に対するものでした [4]。 期間はモデルを公開した8月27日から、修正して再公開した9月9日までです。9月8日にセキュリティ研究者からHackerOne経由で報告を受けて判明し、意図的な悪用の痕跡は見つかっていないとしています。他のWorkers AIのモデルは影響を受けていません [4]。 原因は、処理基盤の設定の不一致と、推論エンジンSGLangの不具合が重なったことと説明しています [4]。

企業・担当者が確認すること： Cloudflareは、SGLangを使って推論基盤を自社運用している事業者に対し、v0.5.22以降への更新を強く推奨しています [4]。Workers AIの利用者に向けた対応の依頼は記載されていませんが、当サイトでは、8月27日〜9月9日にGLM-5.3へ長い入力を送っていた場合、送信内容に機密情報が含まれていなかったかを確認することをおすすめします。

3. 【続報】米CISA、PHPの脆弱性2件（CVE-2026-109618、CVE-2026-109619）を悪用が確認された脆弱性の一覧に追加

米国のCISA（サイバーセキュリティ・インフラストラクチャセキュリティ庁）は2026年10月26日、PHPのメモリ破損の脆弱性（CVE-2026-109618）と、内部の依頼状態が古いまま残る脆弱性（CVE-2026-109619）を、悪用が確認された脆弱性の一覧（KEVカタログ）に追加しました [5]。 いずれも当サイトで既報の脆弱性で、JPCERT/CCも10月26日の注意喚起の更新で、悪用を試みる通信を観測したとの報告が相次いでいるとしています [7]。

企業・担当者が確認すること： PHP 8.5.12、8.4.27、8.3.36、8.2.35より前のバージョンを使っている場合は、修正済みバージョンに更新し、侵害有無の調査を実施してください [7]。

4. ギフティグループ、子会社システムへの不正アクセスでeギフトが不正発行、約5.5億円の損失見込み

ギフティグループは2026年10月26日、連結子会社ギフティが運用するシステムの一部が10月25日に脆弱性を悪用した不正アクセスを受け、eギフトが不正に発行されたと公表しました。利用者が保有するeギフトが不正に使われたものではなく、利用者の資産の減少も確認されていないとしています [6]。 原因となった経路は特定・遮断し、該当システムは10月25日に停止したうえで、今後も利用を再開しない方針です。個人情報の漏えいは確認されていません。損失は約5.5億円を見込み、2026年12月期第4四半期に特別損失として計上する見込みです [6]。

企業・担当者が確認すること： ギフティのeギフト交換サービスを利用している場合は、一時的な利用上の支障が順次解消しているとされているため、自社の配布・交換状況を確認してください [6]。同社はeギフト発行の管理・監視体制の強化に取り組むとしており [6]、当サイトでは、ポイントやギフトを発行するシステムを運用する企業も、発行処理の管理・監視の体制を点検することをおすすめします。
