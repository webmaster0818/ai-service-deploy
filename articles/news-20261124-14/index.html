AI・システム・セキュリティのニュースまとめ（2026年11月24日 14時）

公開 2026-11-24　AIサービス比較ナビ 編集部

2026年11月24日8時の回以降に確認したニュースのうち、公式発表を確認できた7件をまとめました（セキュリティ4件、AI2件、システム1件）。 KARTEへの不正アクセスに伴うZOZO・キヤノンマーケティングジャパンの情報漏えい、メルカリのNotion AI記録の流出、Chrome 158の重大な脆弱性の修正、AWS SSM Agentの暗号鍵共有の問題、AmazonによるDecartの技術取得、AWSのサインイン期間の延長、Claude for Microsoft 365アドインの不具合を取り上げます。

当サイトでは、各社・各機関の公式発表を開いて内容を照合したうえで掲載しています。数字や日付は各項目末尾の出典番号から確認できます。今回の時間帯は新しい公式発表が少なかったため、11月20日〜23日に公表され、これまでの回に載せられなかった発表もあわせて取り上げています。

セキュリティ

1. KARTEへの不正アクセスで、ZOZOは約1,518万人分、キヤノンMJは約366万件の情報漏えいを公表（続報）

ZOZOは2026年11月20日、プレイドの顧客体験プラットフォーム「KARTE」への第三者による不正アクセスにより、同サービス上で管理していたお客様情報等の一部が漏えいしたと公表しました。ZOZOTOWNのお客様（退会者を含む）約1,518万人分の会員ID・年齢・性別・郵便番号が対象で、このうち約4.7万人はログイン名・メールアドレス・電話番号も対象です。WEAR by ZOZOのお客様約1,393万人分、出店ブランドの担当者約2.4万人分も含まれます [1]。 パスワードはKARTE上で管理しておらず対象外で、クレジットカード情報の漏えいは現時点で確認されていないとしています。対象のお客様と担当者には順次個別に連絡するとしています [1]。 キヤノンマーケティングジャパンも同日、同じ不正アクセスにより約366万件のお客さま情報（会員識別ID・都道府県名・市区町村名・郵便番号・年齢・生年月日・性別・メールマガジンの購読情報）が漏えいしたと公表しました。氏名・電話番号・メールアドレス・クレジットカード番号・パスワードは含まれないとしています [2]。

企業・担当者が確認すること： 両社とも、本件に便乗して自社を装った不審なメール・SMS・電話が届くおそれがあるとして、記載されたURLを開かないよう呼びかけています [1][2]。当サイトでは、KARTEを含む外部のマーケティングツールに連携しているデータの項目と件数を棚卸しし、不要な連携を止めることをおすすめします。

2. メルカリ、Notion AIの処理委託先Fireworks AIへの不正アクセスで、従業員の入力内容と回答の記録が流出した可能性

メルカリは2026年11月21日、グループの従業員が社内業務で使う「Notion AI」に入力した内容とAIの回答の記録の一部が、外部に流出した可能性があると公表しました。Notion社がNotion AIの処理の一部を委託していたFireworks AIが第三者による不正アクセスを受け、利用状況を分析するために同社へ送られていた記録が同社の環境に保存されていたことが原因としています [3]。 対象は2026年10月5日〜24日の記録の一部で、お客さま1,522名分、お取引先のご担当者等571名分、採用応募者169名分、派遣社員・業務委託先・退職済みの方1,534名分の情報が含まれます。マイナンバー、クレジットカード番号、お客さまのログインパスワードは含まれていないと確認したとしています [3]。 記録には業務システムの認証情報の一部も含まれており、確認できたものはすべて無効化と再発行を済ませたとしています。11月10日にNotion社から連絡を受け、個人情報保護委員会をはじめとする関係当局に報告したと説明しています [3]。

企業・担当者が確認すること： 当サイトでは、生成AIを組み込んだSaaSを使っている企業は、入力内容がどの委託先に送られ、どれだけの期間保存されるかを提供元の資料で確かめ、認証情報や個人情報を入力しないルールを社内で徹底することをおすすめします。メルカリもNotion AIのチャット機能で取り扱う情報を限定したとしています [3]。

3. Chrome 158の安定版を更新、深刻度「Critical」の脆弱性1件を修正

Googleは2026年11月23日（米国時間）、デスクトップ版Chromeの安定版をWindows・Mac向けに158.0.8127.88/.89、Linux向けに158.0.8127.88へ更新したと発表しました。今後数日から数週間かけて順次配信されます [4]。 今回のセキュリティ修正は1件で、Variations機能の入力検証の不備（CVE-2026-134401）です。深刻度は4段階で最も高い「Critical」で、Googleが2026年8月28日に報告したものです [4]。

企業・担当者が確認すること： 当サイトでは、社内のPCのChromeが158.0.8127.88以降になっているかを管理コンソール等で確かめ、自動更新を待たずに再起動を促すことをおすすめします。

4. AWS、Windows Server AMIのSSM Agentで同じ暗号鍵が共有されていた脆弱性を公表　インスタンスの置き換えを推奨

AWSは2026年11月23日（米国時間）、2026年9月9日より前に公開されたAWS提供のWindows Server AMIに含まれるAmazon SSM Agent（3.3.5226.0未満）で、同じAMIから起動したインスタンス同士がインスタンス登録用の鍵を共有していたと公表しました（CVE-2026-134069）[5]。 既定のホスト管理設定（DHMC）で管理しているインスタンスでは、管理者権限のないローカルユーザーがDHMCロールの認証情報を取得できるおそれがあるとしています。エージェントをその場で更新しても共有された鍵は残るため、9月9日以降に公開されたAMIから起動し直してインスタンスを置き換えるよう推奨しています [5]。

企業・担当者が確認すること： DHMCでWindows Serverを管理している場合は、起動元のAMIの公開日を確かめてください。すぐに置き換えられない場合は、管理者以外のローカルユーザーのアクセスを制限するよう案内されています。エージェントのVaultの削除はDHMCの管理を壊すため対処にならないとしています [5]。

5. Amazon、AI推論の最適化技術「Decart Optimization Stack」とチームを取得へ

Amazonは2026年11月23日、Decartの独自技術「Decart Optimization Stack（DOS）」を購入する契約を結び、共同創業者のDean Leitersdorf氏、Moshe Shalev氏、Orian Leitersdorf氏とチームのAI研究者・エンジニアを迎えると発表しました [6]。 推論と、Trainiumなどの自社設計チップの性能を最適化し、顧客がより速く低いコストでAIモデルを学習・実行できるようにすることが目的としています。両社は2025年からTrainiumでの性能向上に協力してきたと説明しています。取引の完了は規制当局の承認を含む通常の条件に従い、金額は公表されていません [6]。

企業・担当者が確認すること： 当サイトでは、AWSのTrainium・Inferentiaで推論を動かしている、または検討している企業は、今後の性能や料金の案内を確かめたうえで、GPUインスタンスとの費用を比べることをおすすめします。

6. AWS Sign-In、AWS CLIやAIエージェントのサインイン期間を最大90日に設定可能に

AWSは2026年11月23日（米国時間）、IAMユーザー・ロールごとにOAuthサインインのセッション期間（Sign-in duration）を最大90日まで設定できるようにしたと発表しました。開発者やAIエージェントが頻繁にサインインや同意をし直さずに済むようにするもので、固定のアクセスキーより安全な、短期間で更新される認証情報を使う方法としています [7]。 対象はAWS CLI（aws login）、AWS MCP Server、そのほかOAuthに対応したアプリで、マネジメントコンソールのセッションは対象外です。管理者が明示的に長く設定しない限り、これまでの上限は変わりません。すべての商用リージョンで使え、IAMコンソール・CLI・APIで設定できます [7]。

企業・担当者が確認すること： 当サイトでは、AIエージェントや開発者に長いサインイン期間を許す前に、対象のIAMユーザー・ロールの権限を必要な範囲に絞り、固定のアクセスキーを使っている処理をこの方式へ置き換えられるかを検討することをおすすめします。

7. Claude for Microsoft 365のアドインが、Macの個人アカウント利用者で表示されない不具合

Anthropicは日本時間2026年11月24日9時10分、Claude for Microsoft 365のアドインが一部の利用者で表示されなくなっているとステータスページで公表しました。Mac版のExcel・Word・PowerPointで、個人のMicrosoftアカウントでサインインしている利用者が対象で、職場・学校のアカウントとClaudeのほかのアプリは影響を受けていないとしています [8]。 回避策として、office.comからWeb版のExcel・Word・PowerPointを使うよう案内しています。日本時間10時31分の更新では調査を続けているとし、原因は示されていません [8]。

企業・担当者が確認すること： Macで個人のMicrosoftアカウントからClaudeのアドインを使っている場合は、復旧までWeb版のOfficeを使い、ステータスページで最新の状況を確認してください [8]。
