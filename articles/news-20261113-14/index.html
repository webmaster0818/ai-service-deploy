AI・システム・セキュリティのニュースまとめ（2026年11月13日 14時）

公開 2026-11-13　AIサービス比較ナビ 編集部

2026年11月13日14時までに確認したニュースのうち、公式発表を確認できた6件をまとめました（AI 1件、セキュリティ4件、システム1件）。 画像生成AIのComfyUI拡張機能の脆弱性、Citrix NetScaler・Synology DSM・ImageMagickを使うアプリ・VNCビューアの脆弱性、GitHub ActionsのARM32実行環境の提供終了を取り上げます。

当サイトでは、各社・各機関の公式発表を開いて内容を照合したうえで掲載しています。数字や日付は各項目末尾の出典番号から確認できます。時刻は日本時間で記載しています。

AI

1. ComfyUIの拡張機能「ComfyUI-Easy-Use」に認証不要で悪用できる脆弱性、開発者と連絡取れず

CERT/CCは2026年11月12日、画像生成AIのワークフローを組むツールComfyUIの拡張機能ComfyUI-Easy-Use（バージョン1.4.1以前）に、認証なしでファイルを上書きできる脆弱性（CVE-2026-123790）があると公表しました。JVNも11月13日に同じ内容を掲載しています [1][2]。 攻撃者はComfyUIの入力用フォルダにPythonファイルを送り込み、インストール済みのカスタムノードのファイルに上書きできます。ComfyUIを再起動すると、そのコードがComfyUIの権限で実行されるおそれがあります。悪用には、該当する機能に認証なしで攻撃者が届く構成であることが必要です [1]。 CERT/CCは開発者と調整できなかったとしつつ、開発者がmainブランチに修正（コミット8a0f2fc412）を入れたとしています [1]。

企業・担当者が確認すること： ComfyUIでこの拡張機能を使っている場合は、修正を取り込むか拡張機能を外し、ComfyUIに接続できる相手を信頼できる利用者に限ってください [1]。

セキュリティ

2. Citrix NetScaler ADC・Gatewayに脆弱性28件、最も高いもので深刻度9.5

Cloud Software Groupは2026年11月12日、Citrix NetScaler ADCとNetScaler Gatewayの脆弱性28件を公表しました。CVSS v4.0の基本値は、Gateway（SSL VPN、ICAプロキシなど）や認証（AAA）用の仮想サーバーとして設定した場合に影響するCVE-2026-107412が最も高い9.5です。初期設定の機器も対象となるパケット処理の脆弱性（CVE-2026-120868、9.3）も含まれます [3]。 修正版は、14.1-73.57以降、13.1-64.39以降、FIPS版の14.1-73.58 FIPS以降、FIPS・NDcPP版の13.1-37.293以降です。同社は対象の利用者にできるだけ早く更新するよう強く求めています。Citrixが運用するクラウドサービスは同社が更新するとしています [3]。

企業・担当者が確認すること： 自社で運用しているNetScaler ADC・Gatewayのバージョンを確認し、修正版より前であれば更新してください。Secure Private Accessのハイブリッド構成で使っているNetScalerも対象です [3]。

3. Synology、NAS向けOS「DSM」の深刻な脆弱性のアドバイザリを更新

Synologyは2026年11月10日に公開したDSMのセキュリティアドバイザリ（Synology-SA-26:19、重要度Critical）を、11月13日11時41分に更新しました [4]。 認証APIのSQLインジェクションの脆弱性（CVE-2026-76954、CVSS基本値9.8）は、遠隔の攻撃者が任意のファイルを読み書きしたり、サービスを妨害したりできるものです。rsyncの認証回避の脆弱性（CVE-2026-85101、CVSS基本値8.6）もあわせて修正しています。回避策はありません [4]。 修正版はDSM 7.4.1-90080-1、7.3.2-86009-5、7.2.2-72806-10、7.2.1-69057-13の各版以降です [4]。

企業・担当者が確認すること： SynologyのNASを使っている場合は、DSMのバージョンを確認し、修正版より前であれば更新してください [4]。

4. ImageMagickを使うWebアプリなどで、細工した画像によるファイルの読み書きのおそれ

CERT/CCは2026年11月12日、画像処理ソフトImageMagickを、制限の緩いセキュリティ設定のまま使うアプリケーションで、細工したSVGやPostScriptの画像を処理するとファイルを読み書きされるおそれがあると公表しました。JVNも11月13日に掲載しています。構成によっては任意のコードの実行につながる場合があるとしています [5][6]。 CERT/CCは、ImageMagickを使う例としてRuby on Rails、WordPress、MediaWiki、ownCloud Classic、Redmineを挙げ、AIの画像処理の前後の工程でも使われていると指摘しています。ImageMagickだけを更新しても、セキュリティ設定が危険な機能を許したままでは不十分だとしています [5]。

企業・担当者が確認すること： 利用者が画像をアップロードできるシステムでImageMagickを使っていないかを確認し、各製品の更新を適用したうえで、設定ファイル（policy.xml）で必要な形式だけを許可し、MSL・MVG・PS・EPS・PDFなどを無効にしてください [5]。

5. TightVNC・UltraVNCのWindows用ビューアに脆弱性、TightVNCは修正版なし

CERT/CCは2026年11月13日、TightVNCのWindows用ビューア（バージョン1.3.10）と影響を受けるUltraVNCのWindows用ビューアに、ヒープ領域のバッファオーバーフローの脆弱性（CVE-2026-128321）があると公表しました。JVNも同日掲載しています [7][8]。 悪意のあるVNCサーバーに接続すると、細工した画面データによってビューアが異常終了し、任意のコードを実行されるおそれもあります（検証で確認されたのは異常終了のみ）。UltraVNCは1.8.2.8で修正済みで、CERT/CCは1.8.3.1など修正を含む版への更新を勧めています。TightVNCとは連絡が取れず、修正版はありません [7]。

企業・担当者が確認すること： 社内でTightVNCのWindows用ビューアを使っている場合は、修正済みの別のビューアへの置き換えを検討し、それまでは信頼できるVNCサーバーにだけ接続するよう周知してください [7]。

システム

6. GitHub Actions、ホステッドランナーでのARM32ジョブの実行を12月8日までに終了

GitHubは2026年11月12日、GitHub ActionsのホステッドランナーでWindows・LinuxのARM32ジョブの実行を2026年12月8日までに終了すると発表しました。Node 24がARM32に対応していないため、node20のサポート終了に続く措置としています [9]。 ホステッドランナーでの32ビットARM（AArch32）のユーザー空間での実行のサポートも終了します [9]。

企業・担当者が確認すること： ワークフローの中でARM32向けのビルドやテストをホステッドランナーで実行していないかを確認し、12月8日までに代わりの実行環境を用意してください（当サイトの見解）[9]。
