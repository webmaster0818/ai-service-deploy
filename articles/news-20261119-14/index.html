AI・システム・セキュリティのニュースまとめ（2026年11月19日 14時）

2026年11月19日8時の回以降に確認したニュースのうち、公式発表を確認できた4件をまとめました（AI 1件、セキュリティ 3件）。 Anthropicの新規株式公開（IPO）の価格決定、JPCERT/CCによるNode-REDの悪用に関する注意、学習管理システム「Schoo Swing」への不正アクセス、メール配信サービス「blastmail」の不正アクセスに関する報告書の公開を取り上げます。

1. Anthropic、新規株式公開の価格を1株83ドルに決定　ナスダックで11月19日に取引開始予定

Anthropicは2026年11月18日（米国時間）、新規株式公開（IPO）の公開価格をクラスA普通株式1株あたり83.00ドルに決定したと発表しました。売り出し株数は9億8,000万株で、このうち9億5,635万1,354株を同社が、2,364万8,646株を一部の既存株主が売り出します。既存株主の売り出し分の代金は同社には入りません [1]。 株式はナスダック・グローバル・セレクト市場で、ティッカーシンボル「ANT」として2026年11月19日に取引が始まる予定で、払い込みの完了は11月20日を予定しています。引受会社には、追加で最大1億4,700万株を購入できる30日間の権利が付与されています [1]。

2. JPCERT/CC、認証を設定していないNode-REDへの攻撃に注意　国内でも標的に

JPCERT/CCは2026年11月19日、認証（adminAuth）を設定していないNode-REDに、悪意ある制御フロー（フロー）が登録される問題（CVE-2026-58115）について注意を呼びかけました。この脆弱性は2026年8月11日に公表されたものです。Node-REDはSiemensのSIMATIC IoT2050シリーズに同梱されていますが、VulnCheckは、adminAuthを設定せずにNode-REDを組み込んだ製品も同様に影響を受けるおそれがあるとしています [2]。 VulnCheckは2026年11月2日に、この脆弱性を悪用する攻撃の試行を観測したと公表しました。同社が用意した脆弱なホスト環境では、不正なフローが登録され、OSコマンドの実行や不正なプログラムの取得・実行が試みられたとしています。JPCERT/CCも、国内でNode-REDが稼働するホストが攻撃の標的にされたとの報告を受けているとしています [2]。

企業・担当者が確認すること： Node-REDを使っている場合は、Node-REDの「Securing Node-RED」に沿って、HTTPSの有効化、エディタと管理APIの認証（adminAuth）、HTTPノードの保護が設定されているかを確認してください [2]。該当する設定で運用していた場合は、見覚えのないフロー、想定外のOSコマンドの実行、不審な外部通信がないかを調べることが勧められています [2]。

3. Schoo、学習管理システム「Schoo Swing」に不正アクセス　86名分の情報が漏えい

株式会社Schooは2026年11月19日、学習管理システム（LMS）「Schoo Swing」が2026年11月14日未明に第三者による不正アクセスを受け、1校の教員9名の氏名・メールアドレス等と、77校の代表者名・学校の所在地・電話番号（合計86名分）が外部に漏えいしたと発表しました。ログイン用のパスワード、受講者の情報、授業のデータは含まれていないとしています [3]。 第三者は、体験用に提供していた共通アカウント（複数の人が同じIDとパスワードでログインできるアカウント）でログインし、ほかの学校の情報を取得できないようにする制御に不備があった機能を、画面を使わずに直接操作して情報を取得していました。同社は同日5時30分から18時56分までサービスを停止し、機能の修正と共通アカウントの停止を行ったうえで再開しています。11月16日に個人情報保護委員会へ報告しています [3]。

企業・担当者が確認すること： 同社は、漏えいした情報を悪用して同社や学校を装った不審なメールや電話が届くおそれがあるとしています [3]。当サイトでは、自社サービスで体験用・デモ用の共通アカウントを公開している場合は、そのアカウントで取得できるデータの範囲と、画面を通さないAPIの操作でもほかの利用者のデータにアクセスできないかを確認することをおすすめします。

4. 続報：blastmail、不正アクセスの報告書を公開　API サーバーの脆弱性が侵入経路と評価

メール配信サービス「blastmail」を運営する株式会社ラクスライトクラウドは2026年11月18日、不正アクセスに関する報告書を公開しました。外部に公開していた外部連携機能（API）のサーバー2台に第三者が侵入したもので、2026年10月20日18時52分ごろからAPIと管理画面への探索が始まり、20時16分から10月21日0時21分にかけて、販売管理システムと「blastmail」のデータベースから情報を抽出して外部へ送信したとしています。外部の専門機関は、APIのプログラムに残っていた脆弱性が侵入に悪用されたと高い確度で評価しています [4]。 取得された情報は、販売管理システムの全契約者33,382契約分（会社名、担当者の氏名・電話番号・メールアドレス、請求先、契約と支払いの履歴など）と、421契約分の読者（配信先）の名簿、配信したメールの件名・本文などで、同社の調査で確定したとしています。攻撃者の操作開始（20時7分ごろ）から監視による検知（21時52分）まで約1時間45分を要しました。外部の専門機関の正式な報告書は12月上旬に受領する予定です [4]。 同サービスを利用していた株式会社デイトナは2026年11月19日、運営会社の調査の結果、同社がサービスに登録していた取引先などの情報の漏えいは確認されなかったと発表しました [5]。

企業・担当者が確認すること： 「blastmail」を利用していた企業は、報告書と運営会社からの個別連絡を確認し、自社の名前をかたる不審なメールへの注意を取引先に呼びかけることが望まれます [4][5]。外部のメール配信サービスを利用している企業は、配信先の名簿や配信本文がサービス側にどの程度保存されているかを確認し、不要な保存を減らしてください。
