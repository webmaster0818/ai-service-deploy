AI・システム・セキュリティのニュースまとめ（2026年11月12日 14時）

公開 2026-11-12　AIサービス比較ナビ 編集部

2026年11月12日14時までに確認したニュースのうち、公式発表を確認できた7件をまとめました（セキュリティ4件、システム2件、AI1件）。 GitHubの認証情報流出によるサイバーセキュリティクラウドの情報漏えいのおそれ、Apache HTTP Server 2.4.71の公開、ChromeとFirefoxの脆弱性修正、Airターミナル6の脆弱性、OpenAIのWorkspace Agentの障害、Amazon Cognitoのセッション管理、DeepSeek-V4シリーズのSageMaker JumpStart対応を取り上げます。

当サイトでは、各社・各機関の公式発表を開いて内容を照合したうえで掲載しています。数字や日付は各項目末尾の出典番号から確認できます。今回の時間帯（8時〜14時）より前に公表され、前回までのまとめでまだ取り上げていない発表も、発表日を明記して載せています。

セキュリティ

1. サイバーセキュリティクラウド、GitHubの認証情報1件が流出し顧客情報などに漏えいのおそれ（第一報）

サイバーセキュリティクラウドは2026年11月12日、ソフトウェア開発に使っているGitHub上の同社管理領域に不審なアクセスがあり、保存されていた個人情報に漏えいのおそれがあると公表しました。外部機関からの情報提供で、従業員が業務で使っていたGitHubの認証情報1件の流出が判明し、アクセスログの調査で、第三者によるものと考えられる不審なアクセスが過去に行われていたことを11月5日に確認したとしています [1]。 漏えいのおそれがあるのは、一部の顧客に関する情報（企業名、氏名、メールアドレス等）とサービス利用に伴う通信関連情報で、範囲と対象者は調査中です。同社は、確認できるアクセスログの期間や記録内容に制約があり、認証情報が有効だった期間全体のアクセス状況は確認できていないとしています。サービスへの不正アクセスや二次被害は確認されておらず、サービスは通常どおり提供しているとしています [1]。

企業・担当者が確認すること： 同社のサービスを利用している場合は、同社からの案内を確認してください。自社でも、GitHubなどの開発基盤に置いている認証情報や個人情報の棚卸し、従業員の認証情報の管理方法を見直す機会になります（当サイトの見解）。

2. Apache HTTP Server 2.4.71が公開、mod_http2の重要度「critical」の脆弱性を修正

Apache HTTP Serverプロジェクトは2026年11月11日、脆弱性3件を修正したApache HTTP Server 2.4.71を公開しました。最も深刻なCVE-2026-119618（重要度critical）は、mod_http2のassign_headers()における同期の不備により、リモートでコードを実行されるおそれがあるもので、2.4.55から2.4.70までが影響を受けます [2]。 ほかに、mod_mdのNULLポインタ参照で子プロセスが停止するCVE-2026-106023（important、2.4.30〜2.4.70）、mod_vhost_aliasの1バイトのスタックバッファ上書きCVE-2026-109163（low、2.4.69〜2.4.70）が修正されています。JVNも11月12日にこの更新を公表しています [2][3]。

企業・担当者が確認すること： Apache HTTP Serverを使っているWebサーバーで、バージョンと、HTTP/2（mod_http2）やmod_mdを有効にしているかを確認し、2.4.71または各ディストリビューションの修正版へ更新してください [2]。

3. Chrome 157とFirefox 160で多数の脆弱性を修正

Googleは2026年11月11日（米国時間）、デスクトップ版Chromeの安定版を157.0.8103.78/.79（Windows・Mac）、157.0.8103.78（Linux）に更新しました。83件のセキュリティ修正を含み、ServiceWorkerやSkiaなどにおける解放済みメモリの使用（use after free）5件が重要度Criticalとされています [4]。 Mozillaは11月10日（米国時間）、Firefox 160で99件の脆弱性を修正したと公表しました。重要度は最大でhighです [5]。

企業・担当者が確認すること： 社内端末のChromeとFirefoxが最新版に更新されているかを確認し、ブラウザの再起動が済んでいない端末には再起動を促してください（当サイトの見解）。

4. SoftBankのAirターミナル6にOSコマンドインジェクションの脆弱性、利用者の対応は不要

JVNは2026年11月12日、ソフトバンクのAirターミナル6のv1.01.80およびそれ以前に、OSコマンドインジェクションの脆弱性（CVE-2026-101107、CVSS v4.0基本値8.6）があると公表しました。Web管理画面にログインできるユーザーによって、root権限で任意のコマンドを実行されるおそれがあります [6]。 開発者によると、修正済みのファームウェアはすでに展開済みで、インターネットに接続していない機器も接続時に自動で適用されるため、利用者の対応は不要としています [6]。

企業・担当者が確認すること： 拠点や店舗でAirターミナル6を使っている場合は、Web管理画面のパスワードを推測されにくいものにし、管理画面にログインできる人を限っておくことをおすすめします（当サイトの見解）。

システム

5. OpenAIのWorkspace Agentで新規実行ができない障害、14時時点で調査中

OpenAIのステータスページによると、日本時間2026年11月12日7時50分から、ChatGPTのWorkspace Agentで新しい実行を開始できない障害が起きています。影響範囲は「Full outage」と表示され、14時時点でも調査中（Investigating）のままで、続報は出ていません [7]。

企業・担当者が確認すること： Workspace Agentで定型業務を動かしている場合は、実行されていない処理がないか確認し、復旧までの代替手順を決めておいてください。復旧の状況はステータスページで確認できます（当サイトの見解）。

6. Amazon Cognito、ユーザープールのセッション一覧と個別失効に対応

AWSは2026年11月11日（米国時間）、Amazon Cognitoのユーザープールでセッション管理を提供開始しました。ユーザーごとに、すべての端末・アプリクライアントにまたがる有効なSSOセッションとトークンセッションを一覧でき、個別に失効させたり、グローバルサインアウトで全セッションを終了させたりできます [8]。 アプリクライアントごとのSSOセッションの再利用時間を、これまでの1時間固定から設定できるようになり、ユーザーあたりの有効なトークンセッション数の上限も設定できます。EssentialsまたはPlusの機能プランのユーザープールが対象です [8]。

企業・担当者が確認すること： Cognitoで認証を提供しているサービスでは、不正ログインが疑われたときのセッション失効の手順に組み込めるか確認してください。利用中の機能プランが対象かどうかもあわせて確認が必要です [8]。

AI

7. DeepSeek-V4シリーズ3モデルがAmazon SageMaker JumpStartで利用可能に

AWSは2026年11月11日（米国時間）、DeepSeekのDeepSeek-V4-Pro、DeepSeek-V4-Flash、DeepSeek-V4.1-FlashをAmazon SageMaker JumpStartで提供開始しました。いずれもMITライセンスのオープンウェイトのMixture-of-Experts（MoE）モデルです [9]。 V4-Proは総パラメータ1.6兆・1トークンあたり490億を活性化し、100万トークンのコンテキストに対応します。V4-Flashは2,840億パラメータ（活性130億）、V4.1-Flashはマルチモーダルに対応し、最大出力は38万4千トークンとしています [9]。

企業・担当者が確認すること： 自社のAWSアカウント内にオープンウェイトのモデルを置いて使いたい場合の選択肢になります。採用を検討する場合は、自社のデータ取り扱いの方針やGPUインスタンスの費用とあわせて判断してください（当サイトの見解）。
