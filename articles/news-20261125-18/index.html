AI・システム・セキュリティのニュースまとめ（2026年11月25日 18時）

2026年11月25日14時の回以降に確認したニュースのうち、公式発表を確認できた5件をまとめました（セキュリティ4件、AI1件）。 Apache Tomcatの11件の脆弱性、大崎電気工業のランサムウェア被害の第三報、ヒューマンアジャストとインフキュリオンの不正アクセスの続報、Claudeの複数モデルで起きたエラーを取り上げます。

セキュリティ

1. Apache Tomcatに11件の脆弱性、クラスタのTLS-PSK設定に関する1件は「Critical」で修正版は未公開

Apache Tomcatのセキュリティチームは、Tomcat 11.0.29、10.1.62、9.0.124で修正した脆弱性などを公表しています。このうち、クラスタ間通信をTLS 1.3とTLS-PSKで保護している場合に、認証されていないノードがクラスタに参加できる問題（CVE-2026-133325）は深刻度「Critical」で、11.0.28〜11.0.29、10.1.62、9.0.124が影響を受けます。修正を含む11.0.30、10.1.63、9.0.125は未公開で、公開されるまではTLS 1.2に切り替えるよう案内しています [1][2][3]。 クラスタの通信を暗号化するEncryptInterceptorの複数の脆弱性（CVE-2026-95517、深刻度「Moderate」）は修正されず、EncryptInterceptorは非推奨となりました。JVNは2026年11月25日、これらを含む11件の脆弱性を案内しました [1][4]。

企業・担当者が確認すること： Apache Tomcatを使うシステムを運用している企業は、バージョンとクラスタ機能の設定を確かめてください。TLS 1.3とTLS-PSKでクラスタを構成している場合は、修正版の公開までTLS 1.2に切り替えてください [1][2][3]。

2. 続報：大崎電気工業、ランサムウェア被害から11月27日以降に段階的に生産再開、外部へのデータ送信も確認

大崎電気工業は2026年11月25日、ランサムウェアによるサイバー攻撃の第三報を公表しました。埼玉事業所、岩手大崎電気、大崎プラテックの生産を11月27日以降に段階的に再開し、受注済み製品の出荷は12月1日以降、お客様側システムと連携する新規受注は12月7日以降に再開する見通しです [5]。 侵入経路はVPN機器で、社内システムから外部のクラウド型ストレージサービスにデータが送信されたことを確認しました。送信された情報の内容と範囲、個人情報が含まれるかは調査中です。グループ会社の大崎電気システムズも同じVPN機器を経由した不正アクセスを受けていたとしています。生産設備への影響はなく、攻撃者の要求には応じない方針です [5]。

企業・担当者が確認すること： 大崎電気工業と取引がある企業は、受注済み製品の納期や発注について担当の事業部・資材部門からの案内を確かめてください。自社でVPN機器を使っている企業は、外部からの接続の認証方式と多要素認証の適用状況を確かめてください [5]。

3. 続報：ヒューマンアジャスト、委託先「COMSBI」への不正アクセスで5万8,510人と LINE 友だち11万6,518人の情報が漏えい（第二報）

ヒューマンアジャストは2026年11月25日、ソニックムーブが提供するクラウドサービス「COMSBI（SaaS版）」への不正アクセスについて、第二報を公表しました。ソニックムーブの社内用アカウントの認証情報が不正に取得され、2026年11月9日23時4分〜11月10日9時17分に、管理画面からデータ取得用APIを経由して情報が取得されたとしています [6]。 漏えいしたのは、利用者58,510人の氏名・電話番号・メールアドレス・住所・生年月日・性別（いずれかを含む）と、LINE公式アカウントの友だち116,518人の表示名・プロフィール画像（URL）・LINEユーザーIDです。クレジットカード情報は保持していないとしています。11月20日にソニックムーブと連名で個人情報保護委員会に報告しました [6]。

企業・担当者が確認すること： 顧客管理などを外部のクラウドサービスに任せている企業は、委託先の管理画面で2段階認証や接続元IPアドレスの制限が使われているかを確かめてください [6]。

4. 続報：インフキュリオン、「Wallet Station」の漏えい対象の提供先向けに11月26日から提供を再開（第4報）

インフキュリオンは2026年11月25日、ウォレットプラットフォーム「Wallet Station」への不正アクセスについて第4報を公表しました。11月20日の第2報で個人情報の漏えいの対象とした提供先向けに、外部の専門機関による評価を受けて安全性を確認したうえで、11月26日から提供を再開するとしています [7]。 その他の提供先は、提供を再開しているところでは緊急点検を終え、残りは提供先と協議のうえで再開を判断します。漏えいした情報を使った不正利用は現時点で確認されていないとしています。あわせて、第3報の遮断時点の記載を「11月19日の遮断以降」から「11月20日未明の遮断以降」に訂正しました [7]。

企業・担当者が確認すること： Wallet Stationを使ったサービスを利用している企業・個人は、利用しているサービスの提供元のお知らせで再開状況を確かめ、心当たりのない電話・メール・SMSに注意してください [7]。

5. Claudeの複数モデルでエラーが増加、約24分で解決

Anthropicは2026年11月25日、Claude Fable 5.2、Claude Mythos 5.2、Claude Opus 5.5、Claude Sonnet 5.5、Claude Haiku 5.5で、エラーが増える障害があったと公表しました。期間は4時52分〜5時16分（UTC、日本時間13時52分〜14時16分）で、同日5時32分（UTC）に解決を公表しました [8]。

企業・担当者が確認すること： ClaudeのAPIやアプリを業務で使っている企業は、この時間帯に失敗した処理がないかを確かめ、必要に応じて再実行してください [8]。
